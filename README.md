# Walmart Project 1 — Submission Repository

This repository contains the current runnable Walmart Project 1 analysis and its required working submission records. **Financial outputs are provisional, not yet a final independently sourced committee valuation.**

## Run
From the repository root, with Python 3.11+ and no external packages:

```powershell
python walmart_all_models.py
python models/walmart_project1.py
```
